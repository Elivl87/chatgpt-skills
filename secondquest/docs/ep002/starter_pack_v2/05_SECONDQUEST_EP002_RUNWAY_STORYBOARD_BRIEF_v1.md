# SECONDQUEST — EP002
## RUNWAY STORYBOARD BRIEF v1
### DO NOT EXECUTE UNTIL ELI AUTHORIZES STORYBOARD GENERATION

## Purpose
The storyboard only tests the Director's Scene Book: composition, sequence, emotional spacing, camera logic, transitions, Ocarina identity, base-plate consolidation and possible production gaps.

## Absolute rule
Storyboard imagery does **not** enter the final video, art library or canon. Never upscale, animate, crop or recycle it into production. It is discarded after its planning value is extracted.

## Cost strategy
Use the minimum Runway work necessary. Prefer master contact sheets/grouped boards, rough blocks, very few iterations and no beauty variants. Do not spend effort fixing exact faces, hands, stitching, micro-detail or lighting perfection. We need **composition + action + camera + identity + rhythm.**

## Suggested board groupings
A. Hook / Entry — N64 + cartridge; Navi; threshold; outfit transformation; relics; “You.”
B. Childhood / Memory — room; Young Quest + Navi; Saria; Hyrule Field scale; technical joke.
C. Remake / Familiarity — world upgrades; measurable vs familiar; improvement changes memory.
D. Two Audiences — returning iconography; Zelda/Ganondorf/Triforce; Great Deku Tree; same Hyrule/different internal worlds.
E. Time — preservation; 3D depth; Temple of Time; Young→Adult Quest; Master Sword.
F. Return / Growth / Ending — N64 callback; enduring objects; Saria callback; Young road; Adult+Epona; memory-room close; final hero image; CTA.

This does not require six expensive generations. If fewer grouped boards work, use fewer.

## Identity check
Where directed, boards must communicate Quest identity, outfit transformation, Navi, Ocarina, Master Sword, Triforce, Hyrule Field, Saria, Zelda, Ganondorf, Great Deku Tree, Temple of Time and Epona. Do not add excluded characters.

## Output after storyboard
Present storyboard + sequence mapping + any directorial conflict + potential base-plate consolidation. **Do not propose FINAL_ART yet.** Only after storyboard approval begin library audit.
