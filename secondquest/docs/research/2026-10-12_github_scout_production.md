# GitHub scout: production tools for SecondQuest (2026-10-12)

Scope: make stills move on CPU, procedural FX, free SFX/loudness, post-render QC, captions, Claude skills.
Method: WebSearch + raw README/LICENSE fetches. **Verified** = LICENSE/README read directly; **unverified** = only a search snippet (check before use). Nothing was installed or run. Speeds are not measured.
Context: STYLE_BIBLE flags "too static: few cuts, cut-outs don't move". Pipeline: Pillow/NumPy frames -> ffmpeg, 1280x720 design units via S()/F().

## Rejected / weak (honest list)

- **BiRefNet / rembg / BEN2 for automatic layer separation:** BiRefNet-general ~15 s per image on CPU and a ~1 GB ONNX (snippet); weights licences vary (RMBG-2.0 is non-commercial, avoid). Our art is generated on clean backgrounds or we already have cut-outs; low payoff. isnet/u2net (rembg, ~1 s) are an acceptable fallback if one specific plate needs splitting. Licences not verified.
- **Meta AnimatedDrawings as a whole:** MIT, but it retargets human pose onto a drawn humanoid with PyTorch/OpenGL; heavy, wrong style, no gain over #5. Use `arap.py` as reading material only.
- **thorwhalen/an (2D cutout via PixiJS in Chromium):** licence unseen, extra renderer, duplicates what Pillow does.
- **pytweening / easing-lab / easings (PyPI):** trivial curves; 40 lines in lib.py covers them. No Python spring lib found: write the closed-form spring (from #4).
- **Scull, generativepy:** unverified, no fit.
- **Rhubarb forks (wzpan, meshonline):** use upstream.
- **Search gaps:** no good open Python library for ARAP puppet warp with a confirmed licence; no Python sfxr port; no verified ambience-bed repo. These should be built or sourced manually.

## Suggested order of work (cost vs. impact on "static")

1. #1 depth parallax on 2-3 key plates + #4 spring/blur/log-zoom helpers (biggest visible win, free).
2. #5 idle breathing/sway warp on Quest and Pixie (needs no credits; mouth sprites for #2 would).
3. #3 QC gate (loudness + black/freeze/silence) before any final.
4. #6 noise-based FX for water/clouds/rays; #7 / #9 SFX.
5. Captions (#10) only if Shorts need word highlight.

Credits note: nothing here needs paid APIs. #2 mouth shapes and any layer split are the only items that might want new art; draw mouths procedurally first and quote credits only if the Producer prefers painted ones.
