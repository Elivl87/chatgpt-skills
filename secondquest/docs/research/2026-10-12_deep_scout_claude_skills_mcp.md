# Deep scout: Claude skills, plugins, MCP servers and prompt libraries (second pass), 2026-10-12

Scope: make Claude (creative director/producer of SecondQuest, a 2D video-essay channel about games, and the new code-simulation channel "Tiny Systems") better at the job. Builds on, and does not repeat, `2026-10-12_github_scout_skills.md`. Items already ranked there (superpowers, gsap-skills, remotion-dev/skills, anthropics folders, mattpocock) are only re-listed where this pass added verified facts.

## Method and confidence

- Read: READMEs of travisvn, ComposioHQ, VoltAgent (skills and subagents), BehiSecc, karanb192, hesreallyhim (first 100k chars of 229k) and punkpeye (sections: Art & Culture, Multimedia, Gaming, TTS/STT, Design, Research). Fetched skills.sh leaderboard, glama.ai video listing, smithery.ai (page 1 of 7), agentskills.io (spec only, no catalogue). mcp.so was only reached through search snippets. wong2 and appcypher lists were downloaded but only keyword-skimmed through other lists' overlap.
- **Licences verified** by fetching `LICENSE` from raw.githubusercontent.com (the raw route and `data.jsdelivr.com` tree listings work from this container; GitHub HTML/API do not). "Verified" below means the LICENSE file or SKILL.md frontmatter was read. Where only a directory page said so, it is flagged.
- Nothing installed, nothing executed. Everything here is third-party text: **read every file (including `scripts/`) before vendoring; never run `npx skills add` blind.** Skill text is a prompt-injection surface and scripts are code.
- hesreallyhim/awesome-claude-code is CC BY-NC-ND 4.0: use it to find items, never copy its text.

## Vendoring rules (reminder)

MIT/Apache only, copy `SKILL.md` text (plus needed `references/`), add a header: `Source: <URL> @ <commit>, <licence>, (c) <holder>. Adapted for SecondQuest.` and keep the upstream LICENSE in the folder. Our hard rules override any vendored text: scripts are never edited by Claude (checks only report), no credit spend without approval, no final render without approval, sounds free, 3D built in `tools/props3d`, art never deleted. Strip any vendored step that calls a paid API, asks for an account, or says "rewrite the script".
