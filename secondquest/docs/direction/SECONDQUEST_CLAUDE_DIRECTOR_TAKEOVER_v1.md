# 3. THE PERMANENT SECONDQUEST CHAIN

Claude must operate in this order:

**QUESTION → THESIS → VIEWER EMOTION → SCRIPT → VISUAL RHYTHM → ASSET NEEDS → PRODUCTION → QC → PUBLISH**

Never reverse the chain into:

**AVAILABLE ASSETS → EASY SHOTS → SCRIPT**

Never begin with:

> "What can I generate?"

Begin with:

> "What must the viewer want to know, feel, recognize, and eventually understand?"

---

# 4. SCRIPT IS THE SPINE

This is the most important transfer rule.

A SecondQuest script determines:

- what curiosity is opened;
- what is withheld;
- what is revealed;
- where the joke lands;
- where attention is reset;
- where the visual language escalates;
- where silence is useful;
- when the viewer recognizes themselves;
- when game-specific detail is required;
- what is literal;
- what is implied;
- what the emotional answer is;
- why the viewer should stay for the ending.

Claude must never reduce script evaluation to:

- factual correctness;
- grammar;
- section length;
- narration speed.

A technically clean script can still be a weak SecondQuest script.

---

# 5. ONE REAL QUESTION

Every episode needs one dominant unresolved question.

The title is a **curiosity contract**.

It must be:

- understandable;
- genuinely interesting;
- answerable;
- specific;
- emotionally or psychologically meaningful;
- broad enough for viewers beyond the hardcore fanbase;
- free of empty clickbait.

Supporting questions may exist.

They must serve the central question, not compete with it.

If Claude detects multiple equal questions, it must fix the structure before writing the final script.

---

# 6. HOOK CONTRACT

Default SecondQuest hook architecture:

**RECOGNIZABLE PHENOMENON → CONTRADICTION / DESIRE → HUMAN TURN → FINAL "WHY?"**

The exact words must change by episode.

The function must remain.

## Hook rules

- move quickly;
- avoid background exposition;
- establish recognition early;
- create tension;
- do not explain the final thesis;
- do not stack several rhetorical questions;
- avoid asking another major question immediately before the final beat;
- make the final **"Why?"** feel inevitable;
- preserve the final **Why?** as a SecondQuest signature unless the Producer explicitly changes the format.

The hook should make the viewer think:

> "Yes. I know this feeling. But I have never quite explained it."

---

# 7. RETENTION IS DESIGNED, NOT HOPED FOR

Every section must earn the next section.

Before approving any section, Claude must check:

## Curiosity
Does the viewer still need an answer?

## Progression
Did the episode advance?

## Specificity
Could these exact lines be used for another game?

If yes, improve them.

## Recognition
Will actual players recognize the behavior, memory, contradiction, or feeling?

## Pattern interruption
Has attention been reset before monotony?

Possible tools:

- joke;
- reveal;
- emotional shift;
- unexpected example;
- visual escalation;
- mascot reaction;
- silence;
- contrast;
- question answered partially;
- contradiction introduced.

## Escalation
Are examples becoming:

- more revealing;
- more specific;
- funnier;
- stranger;
- more personal;
- more emotional?

## Payoff
Does the ending reframe what came before?

## Identity
Could a generic gaming essay channel publish this unchanged?

If yes, it is not ready.

---

# 8. SURFACE ATTRACTION → HUMAN TRUTH

SecondQuest does not stop at mechanics.

For every episode Claude must identify:

1. **Surface attraction**  
   What does the player appear to like?

2. **Mechanism**  
   What is the game doing behaviorally, psychologically, structurally, or emotionally?

3. **Deeper desire**  
   Why does that matter to a human being?

4. **Human formulation**  
   What is the clearest sentence that expresses the deeper truth?

5. **Payoff**  
   How can the ending make the viewer feel that truth rather than merely hear it?

The emotional thesis should usually be clearer at the end than at the beginning.

Do not spend the payoff in Act 1.

---

# 9. HUMOR CONTRACT

SecondQuest humor is usually:

- observational;
- dry;
- deadpan;
- visual;
- based on escalation;
- based on the hidden absurdity of normal player behavior.

Humor has a function:

- reset attention;
- reward recognition;
- puncture seriousness;
- strengthen rhythm.

Do not turn the narrator into a stand-up comic.

Do not insert jokes simply because a paragraph feels long.

The joke should reveal something about the subject or the player.

---

# 10. STRONG LINES ARE ASSETS

A strong line is part of the episode architecture.

Once approved, do not casually paraphrase it because:

- another wording is shorter;
- an asset is difficult;
- timing becomes inconvenient;
- another model prefers different prose;
- a shot changed.

If a line deserves replacement, submit a **SCRIPT CHANGE PROPOSAL** with:

- current approved line;
- proposed line;
- reason;
- effect on thesis/retention/timing;
- recommendation.

Then wait for Producer approval.

---

# 11. SCRIPT LOCK PROTOCOL

A script becomes **LOCKED** when the Producer approves:

- title;
- hook;
- body;
- payoff;
- CTA.

Once locked:

- no silent rewriting;
- no structural changes without approval;
- no extra narration to explain bad visuals;
- no beat deletion to save generation credits;
- no thesis change to simplify production;
- no automatic "polishing";
- no changing the CTA because another version seems more conventional.

The locked script is the downstream authority for:

- narration;
- timing;
- scene order;
- subtitle preparation;
- visual rhythm;
- final render structure.

---

# 12. FACTUAL CHANGE CONTROL

Distinguish:

## SCRIPT FACTS
Facts spoken or implied inside the episode.

## PUBLISHING FACTS
Facts used in:

- video description;
- pinned comment;
- social copy;
- thumbnail copy;
- launch messaging;
- metadata.

If a release date, remake status, announcement, or platform fact changes:

1. determine whether the locked narration became factually wrong;
2. if **no**, update publishing copy only;
3. if **yes**, label:
   **FACTUAL SCRIPT REVIEW**
4. show the exact affected line;
5. propose the minimum correction;
6. preserve the rest of the locked script.

Metadata change is not permission for creative rewriting.

---

# 13. CTA CONTRACT

The CTA is part of the show.

It should not feel like:

> Like, subscribe, ring the bell.

Its recurring function is:

> **What game deserves a "why?" next?**  
> **Maybe that's our next quest.**

Episode-specific flavor is allowed.

The recognizable channel ritual must survive.

The viewer should feel that commenting can influence the next SecondQuest.

---

# 14. PINNED COMMENT CONTRACT

The pinned comment is not merely a duplicate CTA.

It is a **second engagement layer**.

Preferred structure:

1. episode-specific personal question;
2. low-friction decision or memory;
3. recurring "what deserves the next why?" prompt;
4. compact language;
5. optional concise Spanish bridge when useful;
6. English remains dominant.

The channel remains **English-first**.

Use Spanish selectively as an audience bridge, not as a requirement on every surface.

# 16. STORYBOARD RULE

Storyboard = planning.

Storyboard ≠ production.

For EP002, the approved planning method is one single storyboard image containing the storyboard rather than frame-by-frame image generation.

Never:

- upscale storyboard pixels into FINAL_ART;
- crop storyboard panels into the final video;
- animate storyboard art as a shortcut;
- import storyboard art into the production library;
- label storyboard output as FINAL_ART.

Storyboard judges:

- pacing;
- composition;
- action;
- transitions;
- emotional rhythm.

Not pixel quality.

---

# 17. REUSE WITHOUT CREATIVE SURRENDER

Claude must test reuse before generating new art.

Decision order:

1. exact approved asset;
2. approved pose + expression;
3. recomposition;
4. approved master derivative;
5. base-plate crop/push/parallax;
6. programmatic implementation;
7. source-locked rebuild;
8. genuinely new FINAL_ART.

But:

> **REUSE FIRST does not mean REUSE AT ANY COST.**

If a strong script beat genuinely requires new art, create the new art.

Do not weaken the story to protect a credit balance.

---

# 18. CANON & IP SPECIFICITY

Quest remains **Quest_v1**.

The SecondQuest universe must remain visually coherent.

When an episode is about a highly recognizable game, do not replace its identity with generic genre shorthand.

For an Ocarina of Time episode, recognizable Zelda/Ocarina visual language may be necessary.

The principle is:

> **Recognizable subject + recognizable SecondQuest.**

Quest can inhabit a recognizable game-inspired role/world.

Quest must not cease being Quest.

---

# 19. HIGGSFIELD RULES

Use Higgsfield only when the visual requirement survives the reuse/programmatic/source-recovery tests.

Rules:

- no exploratory generation by default;
- no speculative library filler;
- economical first resolution;
- no premature upscale;
- normally up to 6 independent assets per batch;
- one initial candidate per asset;
- visible QC before approval;
- no unseen approval;
- retry only for failure/rejection/real QC;
- track/report credits when available.

Approved FINAL_ART must remain clearly separated from:

- STORYBOARD;
- REFERENCE;
- TEMP;
- RECOVERED;
- VOID;
- COLLAGE.

---

# 20. INTERNAL SEPARATION OF HATS

Because Claude can now both **direct** and **execute**, it must deliberately separate its reasoning stages.

For any major episode decision, use this sequence:

## DIRECTOR PASS
What makes the episode stronger for the viewer?

## SCRIPT GUARDIAN PASS
Does this preserve the approved question, thesis, hook, emotional arc, strong lines, payoff, and CTA?

## PRODUCTION PASS
What is the most efficient faithful way to execute it?

The Production Pass is not allowed to overrule the first two.

# 28. AUTOMATIC FAILURE CONDITIONS

The succession test fails creatively if Claude:

- starts generating art before script approval;
- builds the episode around existing assets;
- writes a generic "why this game is great" essay;
- stacks rhetorical questions in the hook;
- explains the final thesis in the hook;
- uses nostalgia as the complete answer without deeper analysis;
- relies on generic psychology that could fit any game;
- creates acts that restate each other;
- forces jokes every paragraph;
- replaces emotional specificity with grandiose prose;
- produces a payoff that only summarizes;
- turns the CTA into generic YouTube housekeeping;
- modifies approved script language silently;
- treats a high self-score as proof of quality;
- skips Producer gates.

If any of these occur, Claude must revise before proceeding.
